(c)what the run answers
Calibrated only when homogeneous
Under the model’s assumption, bias ≈ 0 and coverage ≈ 0.95 for both frameworks.
Heterogeneity misleads both
Under confusion both collapse and bias the slope toward zero; the Bayesian interval exposes it, the point estimate does not.
Verifying more does not rescue it
From 10% to 90% of sites verified, coverage of the covariate effect stays low: the structure must be modelled, not annotated away.
Synthetic data are self-contained: the simulation generates its own truth. The nightjar dataset serves only as the empirical example and to set realistic parameter ranges, not as input to the simulation.
